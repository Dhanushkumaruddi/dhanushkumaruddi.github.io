# Dhanush — portfolio (lights on / lights off)

## Put it online (Netlify, free, 2 minutes)
1. Unzip this file.
2. Go to https://app.netlify.com/drop and sign in.
3. Drag the unzipped folder (the one with index.html inside) onto the page.
4. Netlify gives you a link. Under "Site configuration > Change site name" you can rename it, e.g. dhanush-kumar.netlify.app

## What's inside
- index.html – all the text (edit the words here)
- styles.css – colours and layout
- app.js – the pull cord, flip card, doors, rooms and the year timeline
- assets/ – photo, project images, fonts

## How it works
- Pull the cord (top right) to switch lights on/off. The choice is remembered.
- Scroll through the four doors; click the one in front to walk into that room. Esc or "Back to the doors" returns.
- "Let's go back in time" rolls the year back as you scroll.

## Or put it on GitHub Pages
See the Word guide "GitHub-Pages-Guide.docx" — upload everything in this folder (not the folder itself) to a public repository named <username>.github.io, then Settings > Pages > Deploy from branch "main", folder "/ (root)".
